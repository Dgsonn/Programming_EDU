Câu lệnh If-Else: Cánh cổng Quyết định

Chào mừng đến với cửa ải thứ hai. Trong thế giới lập trình, không phải lúc nào dòng code cũng chạy thẳng băng. Đôi khi, bạn phải đưa ra quyết định dựa trên các điều kiện.

Khái niệm cốt lõi

Cú pháp if - elif - else giúp chương trình rẽ nhánh. Nếu điều kiện đúng (True), khối code bên trong sẽ được chạy.

Cú pháp cơ bản:

if dieu_kien_1:
    # Thực hiện hành động A
elif dieu_kien_2:
    # Thực hiện hành động B
else:
    # Thực hiện hành động C nếu tất cả đều sai

Nhiệm vụ của bạn

Hệ thống phòng thủ của trạm không gian đang yêu cầu nhập mật khẩu. Hãy viết một đoạn code bên khung bên phải để:

  • Kiểm tra biến password.
  • Nếu password là "OpenSesame", in ra: "Truy cập cho phép".
  • Nếu không, in ra: "Báo động: Sai mật khẩu!".

Cho mình hỏi tại sao mình dùng dấu "=" trong câu lệnh if (ví dụ if a = 5) lại bị báo lỗi SyntaxError nhỉ?

Mentor_Hoang

Dấu "=" là gán giá trị bạn nhé. Để so sánh bằng nhau trong điều kiện, bạn phải dùng hai dấu bằng "==" nha (ví dụ: if a == 5).
