Tổng quan khóa học

Tuần 3 của học kỳ. Hệ thống USTH StudyLab muốn trả lời một câu hỏi mà không luật if/else nào viết nổi: "học viên nào đang trên đà rớt môn — khi điểm cuối kỳ còn CHƯA tồn tại?" Bạn là người dựng mô hình Machine Learning đầu tiên cho StudyLab.

Qua 15 bài (5 module), bạn đi từ chưa biết ML là gì đến tự tay huấn luyện và đánh giá model trung thực: định nghĩa đúng bài toán, chuẩn bị dữ liệu sạch, hồi quy tuyến tính + gradient descent, phân loại logistic, và nghệ thuật không tự dối mình khi đánh giá (train/validation/test).

Điểm đặc biệt: Python THẬT (numpy, pandas, scikit-learn) chạy ngay trong trình duyệt — không cần cài đặt gì. Mỗi bài kết thúc bằng IDE thật, và bài nộp được chấm 4 tầng như code review thật: Output đúng chưa — Code đúng thứ tự chưa — Model có thật sự học không — và có "chạy được nhưng SAI về nghĩa" không.

Sau khóa học, bạn sẽ làm được:

  • 🎯 Nhận diện đúng loại bài toán ML (regression / classification / clustering) từ câu hỏi + target — không nhìn nhầm theo kiểu dữ liệu lưu trữ
  • 🧹 Chuẩn bị dữ liệu sạch: kiểu dữ liệu ngữ nghĩa, làm sạch, scale — và không bao giờ để lộ target vào X (leakage)
  • 📈 Tự tay huấn luyện Linear Regression, đo lỗi bằng MSE và hiểu gradient descent tự chỉnh đường thẳng thế nào
  • 🎲 Biến điểm số thành xác suất bằng sigmoid và vẽ decision boundary tách 2 lớp
  • 🔬 Chẩn đoán underfit / overfit và chia Train / Validation / Test để đánh giá không tự dối mình
  • 🐍 Viết code ML bằng Python thật — pandas chọn cột theo nghĩa, fit/predict đúng quy trình, qua được cả 4 tầng chấm

💡 Cách học: Mỗi bài 4 bước — Model Story (xem hiện tượng) → Concept Check (kéo thả, phân loại) → Experiment Builder (tự dựng thí nghiệm, xem code sinh ra) → Full Python IDE (tự code, chấm 4 tầng thật).
