    1. Entity Set & Primary Key

    Example 1:
    Input:
  acc_id = 56

Output:
  | username  | is_vip |
  | Ganker99  | true   |

Explanation:
  acc_id = 56 → username = "Ganker99", is_vip = true.
  Dùng WHERE acc_id = 56 để lọc đúng 1 dòng.
    • Table member_accounts có 3 cột: acc_id, username, is_vip
    • acc_id là Primary Key (UNIQUE, NOT NULL)
    • Cần lấy chính xác 1 dòng (dùng acc_id để filter)
    • KHÔNG dùng SELECT * — chỉ lấy 2 cột yêu cầu
