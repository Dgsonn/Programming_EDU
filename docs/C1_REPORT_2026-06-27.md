### Bug fixed during cleanup

Script đầu tiên (v1) miss compound selectors kiểu `.parent .deadChild { ... }` vì `.deadChild` chỉ là 1 token trong selector list — không phải whole selector. Fix:

1. Mở rộng `@` detection: không chỉ check `selector_text.strip().startswith("@")` mà dùng regex `@(media|keyframes|supports|font-face|...)\b` (vì sel_start có thể land ngay sau `*/` của comment trước → selector_text starts with `/` not `@`).
2. Recurse vào body của `@` rules để xử lý nested selectors.
3. Logic remove: bất kỳ selector nào có ít nhất 1 dead class token → remove cả rule block (vì rule không bao giờ apply khi 1 class required không tồn tại trong DOM).

## PHẦN 3: JS HANDLER ENHANCEMENT

### `handleMCQClick` — `D:\PE_test\static\js\lesson_db_design.js:498-548`

**Before (v1):**
```js
const tip = document.createElement('div');
tip.className = 'mcq-wrong-tip';
tip.textContent = opt.explanation || 'Xem lại lý thuyết ở trên.';
btn.appendChild(tip);
setTimeout(() => tip.remove(), 3000);
```

**After (v2 — C1):**
```js
const correctOpt = mcqList[qIdx] && mcqList[qIdx].options && mcqList[qIdx].options.find(o => o.correct);
const wrongExpl = opt.explanation || 'Xem lại lý thuyết ở trên.';
const correctExpl = correctOpt && correctOpt.explanation ? correctOpt.explanation : '';
const tip = document.createElement('div');
tip.className = 'mcq-wrong-tip mcq-wrong-explore';
tip.innerHTML =
  '<div class="mcq-wrong-why">' + escapeHtml(wrongExpl) + '</div>' +
  (correctExpl ? '<div class="mcq-correct-hint">💡 ' + escapeHtml(correctExpl) + '</div>' : '');
// Note: .mcq-option already has position: relative — tip will be positioned inside it.
btn.appendChild(tip);
setTimeout(() => tip.remove(), 5000);  // 5s instead of 3s — give user time to read
```

**Changes:**
1. Look up correct option's `explanation` from `mcqList[qIdx]`.
2. Build tooltip with 2 divs: `.mcq-wrong-why` (red, top) + `.mcq-correct-hint` (green, bottom with 💡).
3. Auto-hide **5s** thay vì 3s (Claude v7 chỉ định).
4. Removed redundant `btn.style.position = 'relative'` vì `.mcq-option` đã có `position: relative` rồi (verified at line 895-912 of CSS).

## NOTES FOR CLAUDE/USER

1. **12 bài fallback text:** B2, B3, B5-7, B9-12, B15, B16, B18 không có `explanation` → user sẽ thấy "Xem lại lý thuyết ở trên." (text chung). Nếu muốn mở rộng scope, có thể làm tiếp với effort ~30 phút cho 12 bài còn lại.

2. **Auto-hide 5s:** Per Claude v7 Phần 10.2. User nên verify visually nếu 5s đủ/không đủ. Có thể bump lên 7-8s nếu explanations dài.

3. **Tooltip position:** Hiện tại tooltip render INSIDE `.mcq-option` button (block-level). Nếu option quá ngắn, tooltip có thể overflow. Chưa thấy issue ở 6 lessons test nhưng cần check trên màn hình nhỏ (mobile đã defer).

4. **`!important` giảm:** Cleanup vô tình xóa 9 rules có `!important` (thuộc các dead classes). Đây là **side-effect tốt** — giảm từ 12 → 3, còn lại đều là `prefers-reduced-motion` (Claude đã cho phép).

5. **`mcq-wrong-explore` class:** Đã thêm vào tooltip.className nhưng KHÔNG có CSS rule riêng (rely trên `.mcq-wrong-tip` parent + 2 children). Đây là intentional — chỉ là class marker cho future styling hooks.
