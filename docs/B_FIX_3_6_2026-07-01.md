### §4.2 — R-B dynamic route (Q2-Q5 user chốt)

**Approach**: viewBox = "0 0 W×H" (dynamic, 1:1 ratio với container px) → path px = station px tự align KHÔNG distort. Revert B1b px→% về px (vì viewBox 1:1, p.x = px trực tiếp).

**Algorithm `computeSerpentineRoute(stations, W, H)`**:
- KHO fixed bottom-left `(90, H-110)` — padX=50, padBottom=110 (chừa chỗ PE hub + sublabel)
- Stations distributed evenly theo execution order:
  - 1 station: `(W*0.5, H-110)`
  - 2 stations: `(W*0.30, H-110)` → `(W-90, 90)`
  - 3 stations: `(W*0.30, H-110)` → `(W*0.55, H*0.50)` → `(W-90, 90)`
  - 4 stations: `(W*0.25, H-110)` → `(W*0.50, H*0.65)` → `(W*0.70, H*0.30)` → `(W-90, 90)`
  - 5+ stations: linear interpolation bottom→top với x = W*(0.25 + t*0.50)
- Path: `M khoPos C ... positions[0] C ... positions[1] ...` (cubic Bezier curves)
- fMap dynamic: `fMap[execStations[i].zone] = (i+1) / n`

**`regenerateRoute()`** (called on init + ResizeObserver):
1. Đo `mapEl.getBoundingClientRect()` → W, H
2. Compute serpentine routeD + fMap
3. Set SVG `viewBox="0 0 W H"` (1:1, no stretch)
4. Update 3 path elements d (shadow, route, flow)
5. Update bgDots positions proportionally (decorative)
6. Position PE hub overlay HTML tại khoPos (px)
7. Re-place stations via getPointAtLength + computed fMap (px)
8. Re-position truck at f=0 (px)
