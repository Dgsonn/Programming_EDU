## Step 2.2: MIGRATE — Replace hardcoded values with tokens (net-zero or negative bytes)

This is the most impactful step. Go through the EXISTING CSS selectors and replace hardcoded values with the tokens you defined in Phase 1.

### 2.2a. Replace hardcoded colors with surface tokens

Find and replace:
```
background: #0B1121  →  background: var(--surface-0)
background: #0F172A  →  background: var(--surface-1)
background: #151E32  →  background: var(--surface-2)
background: #1A2744  →  background: var(--surface-3)
```

These are EXACT matches to your defined tokens. Safe to replace globally.

**Verification:**
```powershell
$css = Get-Content "D:\PE_test\static\css\lesson_db_design.css" -Raw
Write-Host "Hardcoded #0B1121: $(([regex]::Matches($css, '#0B1121')).Count)"
Write-Host "Hardcoded #0F172A: $(([regex]::Matches($css, '#0F172A')).Count)"
Write-Host "var(--surface-): $(([regex]::Matches($css, 'var\(--surface-')).Count)"
# Target: hardcoded counts = 0, var counts > 20
```

### 2.2b. Replace hardcoded spacing with space tokens

Find padding/margin/gap values and replace with CLOSEST token:
```
4px   → var(--space-1)
8px   → var(--space-2)
12px  → var(--space-3)
16px  → var(--space-4)
20px  → var(--space-5)
24px  → var(--space-6)
32px  → var(--space-7)
40px  → var(--space-8)
```

**CAUTION:** Only replace in `padding:`, `margin:`, `gap:`, `top:`, `bottom:`, `left:`, `right:` properties. Do NOT replace in `width:`, `height:`, `font-size:`, `border-radius:`, `box-shadow:`, `line-height:`, or `transform:`.

**Do NOT do bulk find-replace.** Go section by section:
1. First do all `.concept-card` rules
2. Then all `.mcq-option` rules
3. Then all `.step-pane` rules
4. Verify after each section

### 2.2c. Replace hardcoded font-sizes with text tokens

```
11px → var(--text-xs)
13px → var(--text-sm)
15px → var(--text-base)   (NOTE: existing uses 14px a lot — decide if 14→15 is OK or keep 14)
18px → var(--text-lg)
22px → var(--text-xl)
28px → var(--text-2xl)
36px → var(--text-3xl)
```

**CAUTION for 14px:** The codebase uses 14px extensively (JetBrains Mono code font). If converting 14px → 15px looks wrong, add `--text-code: 14px` token specifically for code/monospace contexts.

### 2.2d. Replace hardcoded shadows with shadow tokens

```
box-shadow: 0 1px 3px rgba(0,0,0,.12)    → box-shadow: var(--shadow-xs)
box-shadow: 0 2px 8px rgba(0,0,0,.2)     → box-shadow: var(--shadow-sm)
box-shadow: 0 4px 16px rgba(0,0,0,.3)    → box-shadow: var(--shadow-md)
box-shadow: 0 8px 32px rgba(0,0,0,.4)    → box-shadow: var(--shadow-lg)
```

These may not be exact matches — shadow values vary. Use CLOSEST match. If a shadow has accent color glow (e.g., `box-shadow: 0 0 12px var(--module-accent-glow)`), leave it as-is — glow shadows are different from depth shadows.
