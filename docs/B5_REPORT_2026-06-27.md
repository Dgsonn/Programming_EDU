### Issue #2 (B16 Django ORM — CAO)

**Hiện trạng:**
- Step 4 prompt: *"Viết **Django ORM query** đếm số events theo từng event_type cho user U01. Dùng `values('event_type').annotate(count=Count('event_id...`"*
- Step 4 expected_sql: `SELECT event_type, COUNT(event_id) AS event_count FROM log_events WHERE user_id = 'U01' GROUP BY event_type ORDER BY event_count DESC;` ← **Đây là PLAIN SQL, không phải ORM**

**Vấn đề:** Prompt yêu cầu ORM syntax nhưng answer là SQL. User theo prompt sẽ viết:
```python
LogEvent.objects.filter(user_id='U01').values('event_type').annotate(count=Count('event_id')).order_by('-count')
```
nhưng hệ thống expect raw SQL. → User sẽ bị đánh sai.

**Fix gợi ý (1 trong 2):**
- **Option A**: Đổi prompt thành "Viết SQL query đếm số events..." (giữ expected_sql)
- **Option B**: Đổi expected_sql thành Django ORM code (vd: `LogEvent.objects.filter(user_id='U01').values('event_type').annotate(count=Count('event_id')).order_by('-count')`)

**Recommend Option B** — consistent với title "ORM với Django", teaching value cao hơn.

**KHÔNG tự fix — đợi user.**

### Issue #3 (B17 SQL Injection — TRUNG BÌNH)

**Hiện trạng:**
- Step 4 prompt: *"Viết **lại login query** bằng **Prepared Statement** với `%s` placeholder. **Sau đó viết query đếm số user theo role**"* → Yêu cầu **2 queries**.
- Step 4 expected_sql: `SELECT role, COUNT(user_id) AS user_count FROM user_accounts GROUP BY role ORDER BY user_count DESC;` → **Chỉ có 1 query** (count by role, không phải prepared statement login).

**Vấn đề:** User viết 2 queries theo prompt nhưng chỉ count query khớp expected_sql. Prepared statement login query sẽ bị đánh sai (hoặc ngược lại — user chỉ viết 1 query, khớp).

**Fix gợi ý:**
- **Option A**: Tách thành 2 steps (B17 chỉ dạy prepared statement, bài tiếp theo dạy count) — refactor lớn
- **Option B**: Đổi prompt thành "Viết query đếm số user theo role (chỉ cần 1 query)" — đơn giản hơn
- **Option C**: expected_sql lưu cả 2 queries, format:
  ```sql
  -- Login (Prepared Statement)
  SELECT * FROM user_accounts WHERE username = %s AND password_hash = %s;
  -- Count by role
  SELECT role, COUNT(user_id) ...;
  ```

**KHÔNG tự fix — đợi user.**

### Issue #4 (B12 4NF — THẤP)

**Hiện trạng:**
- Step 4 prompt: *"Tìm **top** khóa học có nhiều textbook nhất."* → "top" implies limit N
- Step 4 expected_sql: `SELECT course_id, COUNT(*) AS textbook_count FROM course_textbook GROUP BY course_id ORDER BY textbook_count DESC;` → **Không có LIMIT**

**Vấn đề:** User có thể hiểu "top" = top 1, top 3, top 5, hoặc ALL sorted. So sánh exact-match sẽ fail nếu user thêm LIMIT khác nhau.

**Fix gợi ý:**
- Đổi prompt thành: "Tìm **top 5** khóa học có nhiều textbook nhất" — specific
- Và thêm `LIMIT 5` vào expected_sql

**KHÔNG tự fix — đợi user.**
