## §8 — Lessons learned (RULE 7)

1. **Xen kẽ > cosine-lấy-mẫu-đều cho minGap constraint.** Cosine có đạo hàm = 0 tại extremes → trạm chụm. Xen kẽ `(i%2===0) ? 0.5 + A : 0.5 - A` với A constant → |Δx| cố định ≥ 2*A_min*W. Envelope organic-nhẹ (A_i varies ±0.06) cho đỡ đều tăm tắp.

2. **Số thực tế vượt dự đoán user.** User dự đoán @960 n=6 max ~85px. F5b thực tế 187px nhờ envelope A_i = 0.30±0.06 → 2*A_i ∈ [0.48, 0.72] × W = 173-260px @960. Đạt 110 dễ dàng. **Honesty matters** — user đã sửa spec "âm thầm hạ target 110→70" thành "khôi phục target ≥110 thật", giữ user trust.

3. **Fix abort bug = feature cốt lõi, không "minor".** User nâng cấp từ "không gấp" → "🔴 FIX luôn" vì cancel → về KHO là core UX promise. Pattern: MỖI animation loop cần check abort token, không chỉ "cắt được" qua global handler.

4. **max-width CẦN width: 100% cho flex item.** `.data-preview { flex: 0 0 auto; max-width: 640 }` KHÔNG cap (content intrinsic 430px wins). Phải thêm `width: 100%` để flex item fill max-width.

5. **Probe phải track animation start point.** runQuery 3 stations × 3s/station = 9s regular flow, then fail animation 1.5s. Probe capture t=2000ms chỉ thấy regular flow mid-station. Phải wait > 9s mới thấy fail animation. Cancel test cần click trong khoảng 100-1500ms (fail-1) hoặc 100-800ms (fail-2), KHÔNG phải sau 300ms+.

6. **Council's "rate-limit fresh" có thể tươi ngay khi viết, stale khi probe chạy.** 30+ phút trôi qua, Flask memory limiter collect ~50 requests trong 1h. Visual verify 2nd run hit 429. Workaround: (a) restart Flask 35s (risky), (b) wait 1h+ for sliding window, (c) accept code-level verify. Đã chọn (c) + document gap.
