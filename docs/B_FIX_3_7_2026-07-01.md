## §1 — F1: Map even-spacing + cap ≤640 center

### §1.1 — Algorithm change (`drag_game.js:199-244`)

**Trước (3.6 R-B):** hardcode positions cho n=1,2,3,4; 5+ branch linear interpolation `x = W*(0.25 + t*0.50), y = yStart + t*(yEnd-yStart)`. Adjacent gap phụ thuộc tuyến tính vào `W/(n-1)` và `H/(n-1)`. Tại @960 n=6 → gap ≈ 87 px (AUDIT) — bó dính.

**Sau (3.7 F1):** Y slot **evenly distributed** qua (n+1) slots giữa khoPos và padTop+40 (kho + n stations + 1 headroom); X **alternating 0.75 ↔ 0.25** để đảm bảo gap Euclidean ≥120 px mọi count × mọi viewport.

```js
// F1 (PHASE 3.7-AUDIT-FIX): even-spacing zigzag
var yStart = khoPos.y;
var yEnd = padTop + 40;
var yStep = (yStart - yEnd) / (n + 1);
for (var i = 0; i < n; i++) {
  var y = yStart - (i + 1) * yStep;
  var xRatio = (i % 2 === 0) ? 0.75 : 0.25;
  positions.push({ x: W * xRatio, y: y });
}
```

|---|---|---|---|---|---|
| @960 | 361×383 | ≈188 | ≈187 | ≈184 | ≈184 |
| @1366 | 544×444 | ≈272 | ≈271 | ≈269 | ≈268 |
| @1600 | 640×444 | ≈320 | ≈319 | ≈317 | ≈316 |
| @1920 | 640×556 | ≈360 | ≈359 | ≈357 | ≈356 |

Tất cả ≥120 px. Worst case @960 n=6 = 184 px (gap target là 120). ✓

**Backward compat:** fMap vẫn `fMap[s.zone] = (i + 1) / n` (giống 3.6) → `driveTruckTo` không đổi. Path Bezier curves giữ nguyên structure.

**Edge case handled:** n=1 → center giữa khoPos.y và padTop+40. (Trước là `H - padBottom` — đặt sát kho, dễ overlap với KHO. Mới ở giữa path.)

## §6 — Lessons learned (RULE 7 pattern)

1. **Zigzag > diagonal linear cho minGap constraint.** Linear `x = W*(0.25 + t*0.50)` cho adjacent gap phụ thuộc `W/(n-1)`. Khi n=6 @960 → gap 87 px (cram). Zigzag alternating 0.75↔0.25 force X diff lớn → gap horizontal dominant → đảm bảo ≥120 px worst case.

2. **Cap CSS đơn giản hơn JS-aspect-aware.** `max-width:640px; max-height:100%` + viewBox 1:1 (3.6 R-B) → map cap tự nhiên theo container ratio, không cần JS tính aspect. Trade-off: map aspect thay đổi theo container (non-square ở màn rộng), nhưng serpentine algorithm đã W×H-aware nên station vẫn align.

3. **FA icon sweep bằng static analysis hiệu quả hơn runtime probe.** Extract unique `fa-*` names từ content file + cross-check FA6 free CSS = 39 icons verified < 1 phút. Runtime probe cần login + 20 navigations = 5+ phút + rate-limit risk.

4. **Visual balance (Q-B) real concern, defer follow-up.** Map cap 640 ở @2560 vs data-preview full column 1080 = visible "lệch trục". Không thuộc F1 spec ("cap map ≤640 center"), nhưng user flag trước khi ship = đúng pattern 3.5b. Flag trong report, để user/council quyết Phase 3.8.
