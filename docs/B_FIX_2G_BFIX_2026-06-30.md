### B1 — Map fit-height (CSS + JS resize observer)

**CSS chain (`lesson_db_design.css`):**
- L8792: `#drag-game-mount` `min-height: 360px → 0` (cho phép co)
- L8796: `.pipeline-root` `min-height: 360px → 0` (override floor cũ)
- L8800: `.town-map-track` `min-height: 360px → 0` (cho phép co)
- L9288: `.town-map` đổi từ `width:100%; aspect-ratio:1/1; max-width:600px;` thành `width: min(600px, 100%); height: min(600px, 100%); aspect-ratio: 1/1; margin: 0 auto;`

**JS ResizeObserver (`drag_game.js` init):**
```js
var sizeMapToParent = function() {
  if (!mapEl) return;
  var r = mountEl.getBoundingClientRect();
  var w = r.width, h = r.height;
  var siblings = Array.from(mountEl.children).filter(c => c !== root);
  var siblingH = siblings.reduce((s,c) => s + c.getBoundingClientRect().height, 0);
  var trackRect = trackEl.getBoundingClientRect();
  var availableW = Math.max(0, w - 40);
  var availableH = Math.max(0, trackRect.height || (h - siblingH - 40));
  var size = Math.min(600, availableW, availableH);
  if (size > 0) { mapEl.style.width = size + 'px'; mapEl.style.height = size + 'px'; }
};
sizeMapToParent();
new ResizeObserver(sizeMapToParent).observe(mountEl);
new ResizeObserver(sizeMapToParent).observe(trackEl);
```

**Lý do cần JS:** CSS `aspect-ratio:1/1 + max-height:100%` KHÔNG ép width khi max-height cap (browser chỉ cap height, không enforce aspect). Verified @1600 cho ra 600×443 (non-square). ResizeObserver set pixel size = min(600, parent_w, parent_h) → VUÔNG.
