### §1.2 — Code (drag_game.js:193-340)

**New helper `catmullRomToBezier(points, α, tension)`:**
```js
function catmullRomToBezier(points, alpha, tension) {
  alpha = (alpha == null) ? 0.5 : alpha;
  tension = (tension == null) ? 0.5 : tension;
  var np = points.length;
  if (np < 2) return [];
  // Phantom endpoints: duplicate first/last
  var ext = [points[0]].concat(points).concat([points[np - 1]]);
  var segments = [];
  for (var i = 1; i < ext.length - 2; i++) {
    // ... centripetal parameterization d01 = d(p0,p1)^α, d12, d23
    // Tangent at p1: t1 = ((p2 - p0) / (d01 + d12)) * d12 * tension
    // Bezier cp1 = p1 + t1, cp2 = p2 - t2
    segments.push({ from: p1, c1, c2, to: p2 });
  }
  return segments;
}
```

## §7 — Lessons learned (RULE 7)

1. **Catmull-Rom centripetal cho spline mượt.** Centripetal α=0.5 tránh cusp/self-loop ở khúc quặt (uniform α=0 dễ thắt nút). Phantom endpoints (duplicate first/last) cho smooth tangent tại KHO + station cuối — Brilliant-style.

2. **Cosine vs Sine cho X distribution.** Cosine `cos(πt)` đối xứng quanh t=0.5, đạo hàm max ở giữa → X biến thiên mạnh nhất ở midpoint, smoothly giảm về 0 tại endpoints. Tránh cluster tại extremes (vấn đề của pure sine).

3. **In-memory state > localStorage cho fail counter.** Persist = trừng phạt user (mở lại sau = fail 1 lần nữa?). Per-session reset = mỗi lần truy cập = full animation (Brilliant-style: forgiving).

4. **Brilliant fail UX = unified model.** Cả sai-đáp-án và lỗi cú pháp → cùng 1 animation. Không "về đích rồi báo sai" — mâu thuẫn nhận thức. Pill + diagnose + retry LUÔN đầy đủ (chỉ rút gọn animation), user luôn biết SAI ở đâu.

5. **Cancellation sạch = global click handler** trong suốt animation. Click bất kỳ (trừ .query-feedback) → cancel + snap. Kết hợp với `runBtnEl.disabled = true` chống race.

6. **Auto-bump best-effort vs strict target.** @960 n=6 với 110px minGap fundamental infeasible (W=361 không đủ). Adaptive target `min(110, max(70, 0.20*min(W,H)))` + best-effort = pragmatic ship. Note trong report, để council/user quyết follow-up (compact station ở mobile?).

7. **Visual evidence = take-2-after-rate-limit-reset.** 90+ phút sau probe 3.7 vẫn 429 → memory limiter persist. Pattern: ship với code review đầy đủ + partial visual (≥2/12 OK), acknowledge gap, retry visual sau reset.
