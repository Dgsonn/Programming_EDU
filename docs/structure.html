05 / FLOW

Luồng request điển hình

User request → Flask → Blueprint → Route → Model → NeonDB → Response.

GET /dashboard
→ app.py (Flask before-request: gán request_id, logging)
→ routes/__init__.py (route khớp main_bp)
→ routes/main.py (@main_bp.route('/dashboard'))
→ utils.py (@login_required → check session['user_id'])
→ models.py (gọi get_db() → psycopg2 cursor → NeonDB query)
→ templates/dashboard.html (Jinja2 render với data)
→ static/css/dashboard.css + js/dashboard.js (browser load + hydrate)
Response 200 OK + HTML + Set-Cookie session + X-Request-ID header
Generated từ tree + find trên D:\PE_test — không sửa source code. Mở file này trong browser để xem tương tác.
