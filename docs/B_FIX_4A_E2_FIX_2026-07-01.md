### 1.2 — Fix #2: Strip alias-prefix khỏi column header

**Trước E2-fix (Bài 10 SQL `SELECT m.member_name, COUNT(*) AS loan_count ...`):**
```
Bảng kết quả:
┌────────────────────────────────┬────────────┐
│ M.MEMBER_NAME                  │ LOAN_COUNT │
├────────────────────────────────┼────────────┤
│ Minh                           │ 5          │
│ Sara                           │ 4          │
│ Yuki                           │ 3          │
└────────────────────────────────┴────────────┘
```
Header `M.MEMBER_NAME` = rò alias-prefix từ E1 (engine đặt joinedRow key là `members.member_name`, projection giữ nguyên cả prefix).

**Sau E2-fix:**
```
Bảng kết quả:
┌────────────────────────────────┬────────────┐
│ member_name                    │ loan_count │
├────────────────────────────────┼────────────┤
│ Minh                           │ 5          │
│ Sara                           │ 4          │
│ Yuki                           │ 3          │
└────────────────────────────────┴────────────┘
```

Implementation:
```js
// Hoisted to module scope (was in if-block → E1 path ReferenceError).
function stripAliasPrefix(col) {
  if (!col || col.indexOf('.') < 0) return col;
  return col.replace(/^\w+\./, '');
}

outCols = projections.map(function(p) {
  if (p.kind === 'agg') return p.alias || (p.fn.toUpperCase() + '(' + p.expr + ')');
  return p.alias || stripAliasPrefix(p.col);     // strip chỉ khi KHÔNG có AS
});
```

Cột có AS giữ nguyên (`loan_count` / `total_revenue` / `post_count`). Edge case trùng-tên-2-bảng (chưa bài nào dính) để nguyên per spec v63 chốt.

### 1.3 — Fix #3: Bài 2 age column (derived attribute)

**Bài 2 SQL** (`player_profile` schema): `SELECT username, address_city, address_dist, (EXTRACT(YEAR FROM CURRENT_DATE) - birth_year) AS age FROM player_profile WHERE p_id = 7;`

`EXTRACT(YEAR FROM CURRENT_DATE)` = current year (PostgreSQL syntax). Trong engine:
- **Trước E2-fix:** parser hiểu là identifier, projection gọi `getRowVal(row, '(EXTRACT(YEAR FROM CURRENT_DATE) - birth_year)')` — joinedRow không có key đó → trả `''`. Cell age RỖNG (silent-wrong — student không hiểu sao cột age trống).
- **Sau E2-fix:** `projectValue(row, col)` detect expression có `(` hoặc arithmetic → gọi `evalSqlExpr(row, expr)`. `evalSqlExpr` parseFactor mới nhận regex `/^\s*extract\s*\(\s*year\s+from\s+(?:current_date|current\s+timestamp)\s*\)\s*$/i` → return `new Date().getFullYear()`. Rồi `currentYear - birth_year` = tuổi.

User chốt (B) Dynamic, không hardcode — implementation:
```js
// In evalSqlExpr's parseFactor:
var extractMatch = /^\s*extract\s*\(\s*year\s+from\s+(?:current_date|current\s+timestamp)\s*\)\s*$/i.exec(s);
if (extractMatch) return new Date().getFullYear();
```

Test verifies `age > 0` chứ không hardcode số cụ thể (vì đổi năm vẫn đúng).

Implementation chain:
```js
function projectValue(row, col) {
  if (col == null) return '';
  var s = String(col);
  if (s.indexOf('(') >= 0 || /\s[\+\-\*\/]\s/.test(s)) {       // expression detected
    var v = evalSqlExpr(row, s);                                // Bài 2: EXTRACT... - birth_year
    if (v !== null && !isNaN(v)) return v;
    if (v !== null && typeof v === 'string') return v;
  }
  return getRowVal(row, s);                                     // plain col ref
}
```

Áp dụng **CẢ 2 paths** (E1 non-aggregate + E2 grouped) — trước E2-fix projection value `getRowVal(row, p.col)` không handle expression. Sau E2-fix: GROUP BY path cũng dùng `projectValue`.

## §3 Bug Discovered + Fixed mid-test

### 3.1 `stripAliasPrefix is not defined` — function scope bug

Initial implementation declared `function stripAliasPrefix(col)` INSIDE `if (isGrouped)` block, but Bài 1/2/3/4/5/6/7/8/18 use E1 path (`else` branch without GROUP BY), which also called `stripAliasPrefix` → ReferenceError.

Trace: `js:3127 stripAliasPrefix is not defined` → engine NULL page → 11/20 fail.

Fix: hoisted `stripAliasPrefix` to module scope (top of `window.PE_runSQL = function(...) {}`), defined BEFORE both `if (isGrouped)` and `else` branches.

### 3.2 Bài 2 age cell empty — projection path missing expression eval

E1 path's projection loop used `getRowVal(r, p.col)` which doesn't compute expressions like `(EXTRACT(YEAR FROM CURRENT_DATE) - birth_year)`. Engine hiểu đó là col-ref literal, joinedRow không có key → trả `''`.

Fix: introduced `projectValue(row, col)` helper, called from BOTH E1 path (non-grouped) and E2 grouped path. Helper detects paren/arithmetic → calls `evalSqlExpr`. Applied to GROUP BY path's `kind:col` branch as well.

`evalSqlExpr`'s `parseFactor`:
- New regex `/^\s*extract\s*\(\s*year\s+from\s+(?:current_date|current\s+timestamp)\s*\)\s*$/i`
- Match → return `new Date().getFullYear()` (dynamic, no hardcode).
