## Goal (per Claude v11 Phần 10.2)

> Hiện tại tất cả 4 steps dùng cùng 1 animation (fade-in generic). Mỗi step nên có animation riêng để tạo variety + signal "đang chuyển sang phase mới" cho learner.

## Approach (đã user xác nhận)

1. **Duration:** Uniform 300ms (`--anim-normal`) cho cả 4 steps
2. **Magnitude:** Dramatic (Brilliant-style) — slide 50px, scale 0.85
3. **Test scope:** 6 bài đầy đủ (B1, B4, B8, B13, B14, B17)

## Design

| Step | Animation | Initial transform | Lý do pedagogy |
|------|-----------|-------------------|---------------|
| **1** (Theory) | Slide from LEFT | `translateX(-50px)` | "Bắt đầu hành trình" — entry from start |
| **2** (MCQ) | Scale POP | `scale(0.85)` + overshoot at 60% | "Thử thách xuất hiện" — pop in attention |
| **3** (Drag-Query) | Expand from CENTER | `scale(0.9) translateY(24px)` | "Mở rộng workspace" — IDE-like expansion |
| **4** (Pure Code) | Slide from RIGHT | `translateX(50px)` | "Bước cuối, tự lập" — arrival at destination |

### File: `static/css/lesson_db_design.css`

**Added 4 keyframes + 4 override selectors + reduced-motion override (lines ~7042-7074):**

```css
@keyframes step1-enter {
  0%   { opacity: 0; transform: translateX(-50px); }
  100% { opacity: 1; transform: translateX(0); }
}

@keyframes step2-enter {
  0%   { opacity: 0; transform: scale(0.85); }
  60%  { opacity: 1; transform: scale(1.04); }  /* overshoot for "pop" */
  100% { opacity: 1; transform: scale(1); }
}

@keyframes step3-enter {
  0%   { opacity: 0; transform: scale(0.9) translateY(24px); }
  100% { opacity: 1; transform: scale(1) translateY(0); }
}

@keyframes step4-enter {
  0%   { opacity: 0; transform: translateX(50px); }
  100% { opacity: 1; transform: translateX(0); }
}

.step-pane[data-step="1"].step-fade-in { animation: step1-enter var(--anim-normal) var(--ease-out-quart); }
.step-pane[data-step="2"].step-fade-in { animation: step2-enter var(--anim-normal) var(--ease-out-quart); }
.step-pane[data-step="3"].step-fade-in { animation: step3-enter var(--anim-normal) var(--ease-out-quart); }
.step-pane[data-step="4"].step-fade-in { animation: step4-enter var(--anim-normal) var(--ease-out-quart); }

@media (prefers-reduced-motion: reduce) {
  .step-pane[data-step].step-fade-in {
    animation: none !important;
    opacity: 1 !important;
    transform: none !important;
  }
}
```

## Design notes

1. **Step 2 overshoot at 60%** — `scale(1.04)` mid-animation gives that "pop" feel (slight overshoot then settle). Classic spring physics approximation via cubic-bezier.

2. **Step 3 from-center expansion** — combines `scale(0.9) + translateY(24px)` so the workspace expands AND rises from below — feels like "opening a panel".

3. **Step 1 vs Step 4 symmetry** — both slide horizontally (50px) but in opposite directions. Suggests "journey from start to end" metaphorically.

4. **Specificity override** — `.step-pane[data-step="N"].step-fade-in` has specificity (0,3,0) vs base `.step-pane.step-fade-in` (0,2,0). Override wins without `!important` on override rules.

5. **Reduced-motion friendly** — 3 !important rules in the override. Accessibility win for users with vestibular disorders.
