### 3. JS changes (`course_db_design.js`)

  { n: 1,  m: 1, t: 'Entity Set & PK' },

- Render `.cd-roadmap-module` per module (×3) with header (badge + name + meta)
- Group into rows of 3 (snake alternating via `direction: rtl`)
- Each row: 3 nodes + empty slots if < 3

**Progress resolution (3-tier):**

```js
fetch('/api/courses-enrolled')
  .then(...)  // 1. Server: apiCompletedCount + CURRENT_LESSON_IDX
  .catch(...) // 2. Fallback: localStorage + server
  // 3. Pure localStorage (offline)
```

For each lesson n (1-18):
- if n in completedSet → `.completed`
- if n === currentIdx → `.current`
- else if n < currentIdx → `.completed` (server fallback)
- else → `.locked` + remove href

**Best-effort localStorage write on click:**
```js
container.addEventListener('click', function (e) {
  var n = parseInt(node.dataset.lesson, 10);
  var stored = JSON.parse(localStorage.getItem('pe_progress_db_design') || '[]');
  if (!stored.includes(n)) stored.push(n);
  localStorage.setItem('pe_progress_db_design', JSON.stringify(stored));
});
```

**Old logic preserved:** `updateLessonStatuses()` still runs for the hidden fallback — provides safety if CSS is overridden.

## Design decisions

1. **Snake via `direction: rtl`** — simpler than absolute positioning, naturally flips row order without manual coordinate math
2. **Module zones with accent bar** — left vertical bar gradient per module, gives clear visual section separation
3. **Boss hexagon with crown** — distinct shape immediately signals "boss" before user reads label
4. **Glow + orbit ring for current** — two animations (scale pulse + dashed orbit) signal "you're here" without being annoying
5. **3-tier progress fallback** — robust against network errors, server lag, and offline state
6. **localStorage write on click** — best-effort persistence, helps users who don't have backend progress tracking

---

## Known limitations

1. **localStorage write only** — backend doesn't accept lesson completion events (no POST endpoint). Future: add `/api/lessons/complete` to sync server.
2. **No animation stagger** — all 18 nodes appear at once. Could add entry animation (slide-in per row) but keeps complexity low for now.
3. **No tooltip on node hover** — node title shows below circle. Could add fuller lesson description tooltip on hover (Brilliant-style).
4. **No progress bar between modules** — shows "X bài" count per module. Could add completion %.
